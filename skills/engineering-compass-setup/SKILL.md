# Engineering Compass setup

Read the repository's root `AGENTS.md` when present. Resolve the active
global package using the [adoption contract](../engineering-compass/adoption.md).
Use its installed version and rules to [configure or verify the repository](setup.md).
For a repository with an older version or an adoption without a recorded
version, report the state and ask the user to invoke Update here.

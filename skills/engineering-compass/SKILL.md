# Engineering Compass

Before dependent planning or changes, establish adoption from the repository's
root `AGENTS.md`. Reuse the entry when already in context. If it adopts Compass,
resolve its approved rule snapshot using [adoption.md](adoption.md). Read that
snapshot's `principles.md` and Context Map and follow all applicable routes
within the snapshot. In a repository without adoption, an explicit request to
adopt Compass goes through the installed Engineering Compass Setup skill.

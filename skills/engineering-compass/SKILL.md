# Engineering Compass

Read or reuse the repository's root `AGENTS.md`. For an adoption, follow
[adoption.md](adoption.md) before dependent planning or edits. Apply
`principles.md` and the Context Map from the active installation once the
versions match. Send an explicit first adoption to the installed Setup skill.

# Engineering Compass update

Read the selected repository's root `AGENTS.md`. For a repository without
an adoption, use Setup. For an existing adoption, follow the
[update workflow](migration-workflow.md) to synchronize the active global
installation with `release`, select the migration from the resulting
package, and verify and apply the changes in this repository.

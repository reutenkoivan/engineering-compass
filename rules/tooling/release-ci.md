# Release and CI

For establishing initial publication/delivery or changing an accepted delivery/version
policy, prepare the comprehensive standard plan for consumer contract, mechanisms,
communication and evidence. Later work uses and maintains the sufficient accepted
mechanisms and conventions. Authored release/no-release intent connects consumer
impact, the actual version policy, communication and evidence; this prescribes no
version structure or extra release workflow. Private unreleased
packages need no automatic changeset. **Default:** use the existing intent owner/native
checks; author explains semantics and operator reviews. Assess accumulated changes against
the last delivered contract; establish initial contract/policy for first delivery. Reuse
exact approval; material new consequences update the decision. Comparison needs no old
implementation retention. Package, format and protocol clocks remain distinct under their policies.

A separate compatibility comparator needs a concrete missed change or proven disproportionate
manual-review cost; it fills the gap without replacing authored intent. Static priority
does not activate speculative SemVer inference, API snapshots or declaration suites.
Prepared intent, verified candidate and actual delivery differ; metadata permits no publish.

**Invariant:** CI/hooks implement approved command policy/graph through canonical owners
with required scope, environment, status and evidence. Jobs/shards preserve completeness
and prerequisites. **Default:** prefer sufficient static/native workflow
validation; changed executable workflows also need relevant actual invocation evidence
for triggers, selection, inputs, status and artifact transfer. YAML/string matching is
not execution evidence.

Scope permissions/credentials to need; follow toolchain version owners. Third-party
GitHub Actions use audited full commit SHAs with readable version explanation; persist
checkout credentials only for actual need. Other platforms use supported equivalents.
Hosted labels may roll; retain actual environment identity when runner software affects
the claim.
